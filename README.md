# JIIT @ IMC 2026 — Student Exhibition & Networking Portal

Official exhibition web application for Jaypee Institute of Information Technology (JIIT) students exhibiting at the **Indian Mobile Congress (IMC) 2026**.

## 🌟 Featured Projects
- **SEHAT**: Smart Edge Healthcare and Telemedicine Device — Integrated on-device AI and diagnostic telemetry for underserved communities.
- **MistMinds**: Edge AQI Device — Real-time particulate matter and environmental monitoring with microclimate intelligence.
- **AgriCar**: Edge AI Agriculture Tech — Autonomous computer vision rover for targeted weed detection and precision spraying.

## 🚀 Tech Stack
- **Frontend**: Vanilla HTML5, Modern CSS3 (Variables, Responsive Grid, SVG Orbits), Vanilla JavaScript
- **Lead Capture & Edge API**: Cloudflare Pages / Workers API with local offline fallback
- **Performance**: Zero external render-blocking font dependencies, optimized WebP imagery (< 700 KB entire website payload)

## 💻 Local Development
```bash
# Start local development server
python -m http.server 8080
```
Open `http://localhost:8080` in your browser.
